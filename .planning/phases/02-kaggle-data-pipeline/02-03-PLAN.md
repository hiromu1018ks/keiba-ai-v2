  <action>
    Per D-05: implement all 8 validation checks. Follow the pattern from src/schemas/audit.py (TYPE_CHECKING guard for pandas, loguru for logging, function-based API).

    Create src/pipeline/validators.py with these functions:

    1. validate_row_counts(source_counts: dict[str, int], parquet_dir: Path) -> dict[str, bool]:
       For each table in source_counts, read Parquet file and compare len(df) to expected count. Return {table_name: bool}.

    2. validate_schema_conformance(parquet_dir: Path) -> dict[str, list[str]]:
       For each table in TABLE_TO_SCHEMA: read Parquet, check that all schema model_fields exist as columns, check dtypes are compatible (str/object for str fields, Int64/int for int fields, float for float fields, boolean for bool fields). Return {table_name: [error_messages]}.

    3. validate_audit(parquet_dir: Path) -> dict[str, list[str]]:
       For each table in TABLE_TO_SCHEMA: read Parquet, call audit_leakage([schema_class], df, f"{table_name} table"). Return {table_name: leaked_columns}.

    4. validate_null_rates(source_stats: dict, parquet_dir: Path, tolerance: float = 0.01) -> dict[str, dict[str, float]]:
       For each table, compare null rate per column between source and Parquet. Flag columns where absolute difference exceeds tolerance. Return {table_name: {column: diff}}.

    5. validate_distributions(source_stats: dict, parquet_dir: Path, tolerance: float = 0.01) -> dict[str, dict]:
       For numeric columns (int/float schema fields), compare min/max/mean between source and Parquet. Return mismatches.

    6. validate_referential_integrity(parquet_dir: Path) -> list[str]:
       Load all 5 Parquet files. Check: every race_id in entry exists in race, every race_id in result exists in race, every race_id in odds_trifecta exists in race, every race_id in payoff exists in race. Return list of error messages.

    7. validate_sample_rows(source_dir: Path, parquet_dir: Path, n_samples: int = 5) -> dict[str, bool]:
       For each table, pick n_samples random rows from Parquet, look up corresponding rows in source CSV, verify values match. Return {table_name: bool}.

    8. validate_value_ranges(parquet_dir: Path) -> dict[str, list[str]]:
       Check: race course_code values in {"01"-"10"}, distance > 0, horse_number >= 1, bracket_num 1-8, age >= 2, weight_assigned > 0. Return {table_name: [error_messages]}.

    9. run_all_validations(raw_dir: Path, parquet_dir: Path, source_counts: dict[str, int] | None = None) -> dict:
       Orchestrates all 8 checks. If source_counts is None, computes them from raw CSV. Returns aggregated results dict with pass/fail per check and overall status. Logs summary with loguru.

    Create tests/pipeline/test_validators.py with test classes following the pattern from tests/schemas/test_audit.py:
    - TestValidateRowCounts, TestValidateSchemaConformance, TestValidateAudit, TestValidateNullRates, TestValidateDistributions, TestValidateReferentialIntegrity, TestValidateSampleRows, TestValidateValueRanges, TestRunAllValidations
    - Use tmp_path fixture to create test Parquet files with known content
    - Use conftest fixtures for sample DataFrames
    - Integration test marked with @pytest.mark.skipif to skip when data/standard/*.parquet files don't exist
    - For logger capture tests: use io.StringIO() + logger.add() + try/finally pattern from test_audit.py
  </action>
