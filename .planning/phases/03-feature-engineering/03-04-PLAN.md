    - df is already sorted by SORT_KEY ["horse_key", "race_date", "race_number"]
    - generate_target() must have been called first (so result_status column exists)
    - Group by horse_key
    - Count prior valid starts (where result_status is NOT in ["scratched", "removed", "no_result"]):
      `df["is_debut"] = df.groupby("horse_key").apply(lambda g: (g["result_status"].isin(["scratched", "removed", "no_result"]) == False).cumsum() == 1).reset_index(drop=True)`
      Alternatively, a cleaner implementation: create a "is_valid_start" boolean column, then:
      `valid_starts_before = df.groupby("horse_key")["is_valid_start"].cumsum() - df["is_valid_start"].astype(int)`
      `df["is_debut"] = (valid_starts_before == 0) & df["is_valid_start"]`

      - A horse whose first entry was scratched (result_status="scratched" or "no_result") has is_debut=False for that entry

    - is_debut is a boolean column
