## Review Feedback Addressed (Cycle 3 -- Root Cause Fix)

| # | Concern | Severity | Root Cause | Fix |
|---|---------|----------|------------|-----|
| 3 | Same-race leakage in finish_time_zscore | HIGH | Row-level expanding window with shift(1) lets earlier runners in the SAME race influence normalization stats for later runners. Each horse is a separate row; shift(1) only skips the CURRENT row, not the current race. | Compute at RACE BOUNDARY level: (1) For each race, compute mean finish_time across all runners. (2) Sort these race-level means by race_date within each (course, distance, surface) group. (3) Apply expanding mean/std with shift(1) on the race-level series. (4) Join the resulting normalization parameters back to every runner in that race. ALL runners in race N see identical stats computed from races 1..N-1. |
| Z-score std==0 edge | MEDIUM | Expanding std can be NaN or 0 for sparse groups | When expanding std is NaN or 0, z-score is set to NaN with explicit guard |

    Implement `parse_finish_time_to_seconds(time_str: str) -> float`:
    - If None or NaN, return np.nan
    - Split on ":" to get minutes and seconds
    - Return float(minutes) * 60 + float(seconds)

    Implement `compute_finish_time_zscore(df: pd.DataFrame) -> pd.DataFrame`:

    **Race-boundary approach (the fundamental fix for same-race leakage):**

    The key insight is that row-level expanding windows with shift(1) only skip the CURRENT ROW, not the current race. With 14 horses in a race, the 14th horse's normalization stats include data from the 1st through 13th horses in the SAME race. This is wrong.

    Instead, the normalization must operate at RACE level:

    **Step 1: Parse finish_time to seconds.**
    `df["finish_time_seconds"] = df["finish_time"].apply(parse_finish_time_to_seconds)`

    **Step 2: Aggregate to race-level means.**
    For each race_id, compute the mean finish_time_seconds across all runners:
    `race_means = df.groupby("race_id").agg(race_ft_mean=("finish_time_seconds", "mean"), race_date=("race_date", "first"), course_name=("course_name", "first"), distance=("distance", "first"), surface=("surface", "first")).reset_index()`
    This gives one row per race with a representative finish time.

    **Step 3: Compute expanding-window stats on the race-level series.**
    Sort race_means by race_date within each (course_name, distance, surface) group. Then compute expanding mean and std with shift(1) at the RACE level:
    ```
    race_means = race_means.sort_values(["course_name", "distance", "surface", "race_date"])
    grp = race_means.groupby(["course_name", "distance", "surface"])
    race_means["norm_mean"] = grp["race_ft_mean"].expanding(min_periods=5).mean().shift(1).values
    race_means["norm_std"] = grp["race_ft_mean"].expanding(min_periods=5).std().shift(1).values
    ```
    The shift(1) here skips the current RACE (one row per race), ensuring no runner from the current race contributes.

    **Step 4: Join normalization parameters back to entry-level DataFrame.**
    `df = df.merge(race_means[["race_id", "norm_mean", "norm_std"]], on="race_id", how="left")`
    All runners in the same race get identical norm_mean and norm_std values.

    **Step 5: Compute z-score.**
    ```
    mask = df["norm_std"].notna() & (df["norm_std"] > 0)
    df["finish_time_zscore"] = np.nan
    df.loc[mask, "finish_time_zscore"] = (df.loc[mask, "finish_time_seconds"] - df.loc[mask, "norm_mean"]) / df.loc[mask, "norm_std"]
    ```
    When std is NaN or 0, z-score stays NaN.

    **Step 6: Clean up intermediate columns.**
    Keep finish_time_seconds (needed for lag features). Drop norm_mean, norm_std (intermediate only).

    Wire into generate() orchestrator: call compute_finish_time_zscore() after convert_margin_to_numeric().
