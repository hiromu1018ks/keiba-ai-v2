## Post-Race Leakage Prevention Summary

The pipeline prevents leakage at four levels:
1. **Column exclusion**: EXCLUDE_FROM_FEATURES blocks all raw post-race columns AND current-race result derivatives (margin_numeric, finish_time_zscore)
2. **Feature allowlist**: FEATURE_COLUMNS explicitly defines what IS a model feature -- anything not in this list is excluded
3. **Temporal shift**: All lag features use groupby("horse_key").shift(N) with N>=1, verified by test
4. **Audit gate**: audit_leakage() runs on final output checking exact column name matches
5. **Temporal invariance test**: Proves that adding future data does not change historical feature values
</threat_model>
