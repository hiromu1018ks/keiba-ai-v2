## Post-Race Leakage Prevention Summary

The pipeline prevents leakage at three levels:
1. **Column exclusion**: Raw post-race columns (finish_position, last_3f, corner_4, margin, etc.) are excluded from feature output via EXCLUDE_FROM_FEATURES constant
2. **Temporal shift**: All lag features use groupby("horse_name").shift(N) with N>=1, verified by test
3. **Audit gate**: audit_leakage() runs on final output, checks exact column name matches against all 3 schema post-race columns
</threat_model>
