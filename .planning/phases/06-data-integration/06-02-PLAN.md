<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Kaggle + scraped Parquet → unified Parquet | Two independently-produced corpora cross into a single merged output. Schema reconciliation + PK dedup are the trust controls. |
| Integration write → existing data/standard/*.parquet | Destructive overwrite (D-03) of Phase 2/4 outputs. Atomic write + regenerable sources are the safety controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05 | Tampering | Pre-dedup duplicate race_id (Kaggle/scraped boundary overlap) | mitigate | integrate_standard_layer raises ValueError on any duplicate PK post-concat pre-dedup (Pitfall 6). Refuses to silently drop_duplicates away boundary collisions. Verified by test_no_duplicate_race_ids (hermetic FAIL-LOUD assertion). |
| T-06-06 | Tampering | `pd.concat` without reindex inflating schema | mitigate | Both Kaggle and scraped frames are reindexed to `list(Schema.model_fields.keys())` BEFORE concat (Pattern 1); post-concat column count == Schema field count (hard invariant). |
| T-06-07 | Denial of Service | Half-written `data/standard/*.parquet` if process interrupted | mitigate | Reuse `_atomic_write_parquet` from normalizer.py:643-653 (temp file + os.replace POSIX-atomic). No half-written file possible. |
| T-06-08 | Information Disclosure | Provenance leak via `source` column | mitigate | D-05 anti-pattern guard: integration module MUST NOT add `source` column. Rows indistinguishable (success criterion #2). Verified by grep gate in acceptance_criteria. |
| T-06-09 | Tampering | `errors='ignore'` silently dropping bad dtype conversions | mitigate | `_recast_to_canonical` raises TypeError on failure; NEVER uses errors='ignore'. Verified by grep gate + test_kaggle_recast_raises_on_bad_data (Plan 06-01). |

Module does NOT iterate TABLE_TO_SCHEMA.keys(). Verified by test_odds_payoff_not_overwritten (sentinel file unchanged post-integration). |
| T-06-SC | Tampering | No package installs (all deps pre-installed per Phase 4 audit) | accept | No new dependencies. |
