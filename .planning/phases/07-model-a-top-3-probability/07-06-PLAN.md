(2) `compute_ece(y_true: np.ndarray, y_prob: np.ndarray, n_bins: int = 10) -> float`:
  - RESEARCH Code Examples lines 596-622 の VERIFIED コード採用。Guo et al. 2017 の ECE 定義。
  - ECE = Σ_m (|B_m| / N) × |acc(B_m) - conf(B_m)|。equal-width bins [0, 0.1), [0.1, 0.2), ..., [0.9, 1.0]。最終 bin は閉区間。
  - bins = np.linspace(0.0, 1.0, n_bins + 1)、bin_indices = np.digitize(y_prob, bins[1:-1], right=False)。各 bin で acc = y_true[mask].mean()、conf = y_prob[mask].mean()、ece += (bin_size / n) * abs(acc - conf)。
  - 完全予測で 0.0・D-11 成功基準 ECE < 0.02。
