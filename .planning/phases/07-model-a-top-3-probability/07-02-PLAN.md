**Cycle-2 HIGH #2 fix (sentinel unification):** Codex Cycle 2 review は 07-02 spec が `expected_counts == {}`（空 dict）で bypass を gate していたが tests/run_train call sites は `expected_counts=[]`（空 list）を使っている不整合を指摘した。UNIFIED sentinel を採用: `expected_counts=None`（デフォルト）= 本番行数 assert・`expected_counts=[]`（空 list）= bypass・dict with specific keys = カスタム assert。**{}（空 dict）は使わない**。spec/signature/tests/07-07 run_train forwarding/hermetic E2E call site 全てが同一の sentinel と型を使う。
