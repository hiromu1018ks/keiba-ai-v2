  - 各 fold で: fold_train = df.iloc[train_idx]、fold_val = df.iloc[val_idx]。**D-04 discretion**: fold_train を src.ml.group_timeseries_split.split_train_validation（07-03 で実装・本タスクでは関数存在を仮定）で学習本体と early-stopping val に分割。ただし 07-03 と並列実行するため、本タスクは `from src.ml.group_timeseries_split import split_train_validation` を関数内 import（lazy）にし、07-03 完了後に動作する。ユニットテストでは lazy import を回避するためモックまたは最小 inline 切り出しを使う。
  - train_fold_model で fold モデルを学習。fold_val に対して predict_proba[:,1] で p_top3_raw を予測。
  - 各 fold の val 予渵を race_id, horse_race_id, p_top3_raw, target_top3, fold=i の DataFrame として蓄積。全 fold 結合して返す。
  - logger.info で fold 毎の行数・予測完了を出力。

  - return clf（Phase 8 に .txt で引き渡す・run_train が booster_.save_model で保存）。
