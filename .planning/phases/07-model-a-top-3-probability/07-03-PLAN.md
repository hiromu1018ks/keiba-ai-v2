  - docstring に D-03 要件（同一 race_id 同一 fold・race_date 時系列順・fold=5）と「呼び出し側が race_date 昇順でソート済みである前提」を明記（RESEARCH Pattern 1 docstring 準拠）。mlxtend ではなく独自実装した理由（CLAUDE.md 精神・Phase 8/9 再利用）も記載。
  - `__init__(self, n_splits: int = 5)`: self.n_splits = n_splits。
  - `get_n_splits(self, X=None, y=None, groups=None) -> int`: return self.n_splits。
  - `split(self, X, y=None, groups=None)`: 
    - groups（race_id 配列）が None なら ValueError("groups (race_id) は必須") を raise。
    - `unique_groups = pd.unique(groups)` で出現順のユニーク race_id（呼び出し側が race_date 昇順ソート済み前提）。
    - n_groups = len(unique_groups)。n_groups < n_splits なら ValueError。
    - `_compute_fold_sizes(n_groups)` で n_splits 個の val chunk サイズを計算（base = n_groups // n_splits, rem = n_groups % n_splits, [base + (1 if i < rem else 0) for i in range(n_splits)]）。expanding window（Open Question #2 推奨）: fold i の val = i 番目の chunk、train = 0..i-1 番目の chunk 全て。
    - boundaries = np.cumsum(fold_sizes)。start=0 からループし、各 fold で val_groups = unique_groups[start:boundaries[i]], train_groups = unique_groups[:start]。np.isin(groups, train_groups) で train_mask、np.isin(groups, val_groups) で val_mask を作り、np.where で行インデックスに変換して yield。
    - logger.debug で各 fold の train/val race 数・行数を出力（per-fold ログ・per-row 禁止）。
  - docstring に使い方を明記: `splitter = GroupTimeSeriesSplit(n_splits=5); for train_idx, val_idx in splitter.split(X, y, groups=race_ids): ...`
