race_id グループ化 + race_date 時系列順で fold 境界を切る GroupTimeSeriesSplit（sklearn BaseCrossValidator 準拠）を実装する。sklearn 標準 TimeSeriesSplit は行単位で分割するため同一レースの馬が別 fold に割れ、Phase 8 Harville 計算時にレース内 p_top3 整合性が崩れる問題（D-03 根拠）を構造的に解消する。

**Codex HIGH #1 fix (07-03 fold-0 empty train):** 旧アルゴリズムは `_compute_fold_sizes` で `n_splits` 個の chunk を作り fold 0 の train = chunks[:0] = 空 になる構造的バグがあった。新アルゴリズムは `n_splits + 1` chunks（chunk 0 = warm-up train, chunks 1..n_splits = 各 fold の validation）を採用し、fold i の train = chunks 0..i（cumulative/warm-up 常に含む）・val = chunk i+1 とする。これで fold 0 も warm-up chunk を train として持ち、空 train が起きない。

  - `__init__(self, n_splits: int = 5)`: self.n_splits = n_splits。
  - `get_n_splits(self, X=None, y=None, groups=None) -> int`: return self.n_splits。
  - `split(self, X, y=None, groups=None)`:
    - groups（race_id 配列）が None なら ValueError("groups (race_id) は必須") を raise。
    - `unique_groups = pd.unique(groups)` で出現順のユニーク race_id（呼び出し側が race_date 昇順ソート済み前提）。
    - n_groups = len(unique_groups)。n_groups < n_splits + 1 なら ValueError（warm-up + n_splits val chunks に分割するため最低 n_splits+1 groups 必要・Codex HIGH #1 fix で n_splits から n_splits+1 に変更）。
    - **`_compute_fold_sizes(n_groups)` で n_splits+1 個の chunk サイズを計算**（Codex HIGH #1 fix: 旧 n_splits から n_splits+1 に変更）: base = n_groups // (n_splits + 1), rem = n_groups % (n_splits + 1), return [base + (1 if i < rem else 0) for i in range(n_splits + 1)]。これで n_splits+1 chunks が作られる。
    - boundaries = np.cumsum(fold_sizes)。**新ループ（Codex HIGH #1 fix）**: 各 fold i (0..n_splits-1) で: val_start = boundaries[i]（chunk i の終わり = chunk 0..i の累積）、val_end = boundaries[i+1]（chunk i+1 の終わり）。val_groups = unique_groups[val_start:val_end]。train_groups = unique_groups[:val_start]（chunk 0..i = warm-up + 前 fold までの val chunks・cumulative expanding window）。これで fold 0 の train = unique_groups[:boundaries[0]] = chunk 0（warm-up・非空）。
    - np.isin(groups, train_groups) で train_mask、np.isin(groups, val_groups) で val_mask を作り、np.where で行インデックスに変換して yield。
    - **Runtime temporal order assertion（Codex MEDIUM suggestion）**: X が DataFrame で race_date 列を持つ場合、`assert X.iloc[train_idx]["race_date"].max() < X.iloc[val_idx]["race_date"].min()` を各 fold で実行（temporal leakage の実行時検出）。X が DataFrame でない場合は assertion をスキップ（型ガード）。
    - logger.debug で各 fold の train/val race 数・行数・warm-up 常時含入を出力（per-fold ログ・per-row 禁止）。
  - docstring に使い方を明記: `splitter = GroupTimeSeriesSplit(n_splits=5); for train_idx, val_idx in splitter.split(X, y, groups=race_ids): ...`
