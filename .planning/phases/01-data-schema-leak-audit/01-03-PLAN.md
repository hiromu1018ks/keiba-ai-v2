  <action>
    Create src/schemas/audit.py with two functions following the verified pattern from RESEARCH.md Code Examples.

    Import structure:
    - from pydantic import BaseModel
    - from loguru import logger (per CLAUDE.md fixed choice for logging)
    - from typing import TYPE_CHECKING
    - if TYPE_CHECKING: import pandas as pd (Pattern D from PATTERNS.md -- keeps pandas as type-hint-only dependency)

    Function get_post_race_columns(model_class: type[BaseModel]) -> set[str]:
    - Iterate model_class.model_fields.items()
    - Read info.json_schema_extra from each FieldInfo
    - If extra is dict and extra.get("pre_race", True) is False, add name to post_race set
    - Return the set of post-race column names

    Function audit_leakage(model_classes: list[type[BaseModel]], df: pd.DataFrame, context: str = "feature generation") -> list[str]:
    - Collect all post-race column names from all model classes via get_post_race_columns
    - Check each column in df.columns against the post-race set using EXACT name matching (no substring, no contains)
    - If leaked columns found: logger.warning() with message including context and column names (per D-12: warning only, NO exception)
    - If no leakage: logger.info() with message including context
    - Return list of leaked column names for caller inspection

    Create tests/schemas/conftest.py with shared fixtures:
    - sample_pre_race_df: DataFrame with only pre-race column names (e.g., "race_id", "horse_number", "distance")
    - sample_post_race_df: DataFrame with post-race column names (e.g., "finish_position", "popularity", "win_odds")
    - sample_mixed_df: DataFrame with both pre-race and post-race columns
    - sample_lag_feature_df: DataFrame with lag feature column names like "prev_1_last_3f", "prev_1_corner_4"
    - model_classes fixture: list of [EntrySchema, RaceSchema] (or other combinations as needed)
