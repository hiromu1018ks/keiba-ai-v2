1. Create `src/scraper/models.py` defining `RaceRef` as a frozen dataclass:
   - `@dataclass(frozen=True)` with two fields: `race_id: str` (12-digit) and `race_date: datetime.date`.
   - Module docstring explaining: "race_date is the source of truth for raw HTML path {YYYY}/{MM}. race_id[4:6] is the JRA course code, NOT a calendar month, and MUST NOT be used to derive a path."
   - Imports: `from dataclasses import dataclass`, `import datetime`.

2. Create `src/scraper/enumeration.py` with a DEPENDENCY-INJECTED design: enumeration functions accept a `fetch_html: Callable[[str], Optional[str]]` callable so they never launch a browser themselves (browser lifecycle is owned by the Plan 03 session). Provide these public functions:

   a. `parse_calendar_month_html(html: str) -> list[tuple[str, datetime.date]]`:
      - BS4 (`features="lxml"`) parse of a monthly calendar page.
      - Extract race-DAY links (links whose href matches `/race/list/(\d{8})/` or the documented netkeiba race-day URL pattern). For each, return `(day_url_path, race_day_date)` where race_day_date is parsed from the 8-digit YYYYMMDD segment.
      - Tolerate cancelled race days: an entry with zero race-day links for a date returns nothing for that date (do NOT raise).
      - Return an empty list (not None) when the page has no day links.

   b. `parse_race_day_html(html: str, race_day_date: datetime.date) -> list[RaceRef]`:
      - Parse a race-day (race list) page; extract individual race links matching `/race/(\d{12})/`.
      - For each match, validate `re.fullmatch(r"\d{12}", race_id)`; if it fails, `logger.warning` and skip.
      - Construct `RaceRef(race_id=race_id, race_date=race_day_date)` — the race_date comes from the enclosing day, NOT from the race_id substring.
      - Return list (possibly empty).

   c. `enumerate_race_day_urls(year: int, month: int, fetch_html: Callable[[str], Optional[str]]) -> list[tuple[str, datetime.date]]`:
      - Build the calendar URL `https://db.netkeiba.com/race/calendar/{year}{month:02d}/`, call `fetch_html(url)`.
      - If `fetch_html` returns None, log warning and return `[]` (do NOT raise — the orchestrator decides whether to retry).
      - Delegate parsing to `parse_calendar_month_html`.

   d. `enumerate_races_for_day(day_url: str, race_day_date: datetime.date, fetch_html: Callable[[str], Optional[str]]) -> list[RaceRef]`:
      - Call `fetch_html(day_url)`; if None, log and return `[]`.
      - Delegate parsing to `parse_race_day_html(html, race_day_date)`.

   e. `enumerate_races(start_date: datetime.date, end_date: datetime.date, fetch_html: Callable[[str], Optional[str]]) -> list[RaceRef]`:
      - Iterate every `(year, month)` from `start_date` to `end_date` inclusive.
      - For each month: call `enumerate_race_day_urls(year, month, fetch_html)`.
      - Filter day dates to the `[start_date, end_date]` range (so partial months at the boundaries respect D-05's 2026-05-31 cutoff).
      - For each valid day: call `enumerate_races_for_day(day_url, day_date, fetch_html)`.
      - Accumulate `RaceRef` results, then deduplicate by `race_id` (keep first occurrence — preserves stable order).
      - Return the deduplicated `list[RaceRef]`. Do NOT collapse to bare strings.

   Module-level constant: `_RACE_ID_RE = re.compile(r"\d{12}")` for fullmatch validation. Module imports: `re`, `datetime`, `from typing import Callable, Optional`, `from bs4 import BeautifulSoup`, `from loguru import logger`, `from src.scraper.models import RaceRef`.

3. Do NOT modify `src/scraper/__init__.py`. The package stays import-safe until Plan 06.
