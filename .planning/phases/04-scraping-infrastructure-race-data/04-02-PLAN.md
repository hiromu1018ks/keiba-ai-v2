Per D-02 (Playwright), D-06 (raw dir: data/raw/netkeiba/{YYYY}/{MM}/), D-07 (filename: {race_id}.html), D-08 (dedup by race_id), SCRP-05 (duplicate prevention):

1. Create `src/scraper/fetcher.py` with these functions:

   a. `fetch_with_retry(url: str, output_path: Path, retries: int = 3) -> bool`:
      - Uses sync_playwright to launch headless Chromium, navigate to url with wait_until="networkidle" and timeout=30000
      - On success: writes page.content() to output_path with encoding="utf-8", returns True
      - On PlaywrightTimeout or Exception: logs warning with attempt number, retries with exponential backoff (base 2s * attempt)
      - After max retries: logs error, returns False
      - Module-level constants: MAX_RETRIES = 3, RATE_LIMIT_SECONDS = 2.0

   b. `fetch_race_html(race_id: str, raw_dir: Path = Path("data/raw/netkeiba"), rate_limit_seconds: float = 2.0) -> Path`:
      - Extracts year = race_id[:4], month = race_id[4:6]
      - Computes out_dir = raw_dir / year / month, out_path = out_dir / f"{race_id}.html"
      - SCRP-05 dedup: if out_path.exists() and out_path.stat().st_size > 0, log info "Skipping existing {race_id}" and return out_path
      - Constructs URL: f"https://db.netkeiba.com/race/{race_id}/"
      - Calls fetch_with_retry(url, out_path)
      - Applies rate limiting with time.sleep(rate_limit_seconds) after successful fetch
      - Returns out_path

   c. `enumerate_race_ids(start_year: int = 2022, start_month: int = 1, end_year: int = 2026, end_month: int = 5) -> list[str]`:
      - Per D-04: iterates months from start_year/start_month to end_year/end_month
      - For each month: constructs URL f"https://db.netkeiba.com/race/calendar/{year}{month:02d}/"
      - Fetches calendar page via Playwright (single browser context, reused across months)
      - Parses with BeautifulSoup + lxml: extracts all links containing "/race/" in href
      - From each link href, extracts race_id (12-digit numeric from URL path after /race/)
      - Deduplicates via sorted(set(race_ids))
      - Applies 1.0s rate limit between calendar page fetches
      - Returns sorted unique race_id list

2. Create `tests/scraper/conftest.py` with shared fixtures:
   - `sample_race_html(tmp_path)`: creates a temporary HTML file mimicking netkeiba race result page structure (minimal but parseable -- include `<p class="smalltxt">` with date/race info, a table with class "race_table_01" with a few rows)
   - `tmp_raw_dir(tmp_path)`: Path to tmp_path / "data" / "raw" / "netkeiba" with mkdir
   - `tmp_standard_dir(tmp_path)`: Path to tmp_path / "data" / "standard" with mkdir (reused from pipeline conftest pattern)

Imports: from pathlib import Path, import time, import re, from loguru import logger, from playwright.sync_api import sync_playwright, TimeoutError as PlaywrightTimeout, from bs4 import BeautifulSoup
