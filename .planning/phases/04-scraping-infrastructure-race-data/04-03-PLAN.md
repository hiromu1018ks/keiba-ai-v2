Create `src/scraper/fetcher.py` with these symbols:

1. Module constants: `MAX_RETRIES = 3`, `RATE_LIMIT_SECONDS = 2.0`, `_RACE_ID_RE = re.compile(r"\d{12}")`.

2. `class FetcherSession`:
   - A context manager (`__enter__` / `__exit__`) that launches ONE Playwright Chromium browser and ONE BrowserContext for the entire batch. Cleanup MUST be in `__exit__` via try/finally so a crash mid-batch still closes the browser.
   - Constructor params: `headless: bool = True`, `rate_limit_seconds: float = RATE_LIMIT_SECONDS`, `navigation_timeout_ms: int = 30000`, `wait_until: str = "domcontentloaded"` (NOT `"networkidle"` per Codex Review MEDIUM — networkidle is unreliable on pages with persistent requests).
   - `__enter__` starts `sync_playwright()`, launches `p.chromium.launch(headless=headless)`, creates `browser.new_context()` and one reusable `page = context.new_page()`. Returns `self`.
   - `__exit__` closes page/context/browser and stops playwright, all in a try/finally.
   - Method `fetch(url: str) -> Optional[str]`: navigates `self.page.goto(url, wait_until=self.wait_until, timeout=self.navigation_timeout_ms)`, returns `self.page.content()`. On `PlaywrightTimeout`/Exception: log warning with attempt counter, return None. Applies `time.sleep(self.rate_limit_seconds)` on BOTH success and error paths (Codex Review MEDIUM — server errors must not trigger unthrottled retries).
   - Method `fetch_with_retry(url: str, retries: int = MAX_RETRIES) -> Optional[str]`: calls `self.fetch` up to `retries` times with exponential backoff (base `RATE_LIMIT_SECONDS * (attempt + 2)`). Returns the HTML string on success, or None after exhausting retries (per Codex Review HIGH — do NOT return a path on failure).

3. `def detect_block_page(html: str) -> bool`:
   - Returns True if the HTML looks like an anti-bot / CAPTCHA / empty-result page. Detection heuristics (any one triggers True): HTML length < 500 bytes; presence of substrings `"アクセス制限"`, `"robot"`, `"captcha"`, `"403 Forbidden"`; OR absence of a result-table indicator (`"race_table_01"` not in html AND `"result"` not in html.lower()).
   - Used by `fetch_race_html` to reject block pages as fetch failures.

4. `def fetch_race_html(race_ref: RaceRef, session: FetcherSession, raw_dir: Path = Path("data/raw/netkeiba")) -> Optional[Path]`:
   - Accepts a `RaceRef` (per HIGH #1 — race_date is the source of truth for the path). Assert/validate `re.fullmatch(_RACE_ID_RE, race_ref.race_id)` and raise `ValueError` if invalid (do NOT silently proceed).
   - Derive path from `race_ref.race_date`: `year = f"{race_ref.race_date.year:04d}"`, `month = f"{race_ref.race_date.month:02d}"`, `out_dir = raw_dir / year / month`, `out_path = out_dir / f"{race_ref.race_id}.html"`. NEVER use `race_ref.race_id[4:6]` for the month.
   - SCRP-05 dedup: if `out_path.exists() and out_path.stat().st_size > 0`: log info "Skipping existing {race_id}", return `out_path`.
   - Construct URL `f"https://db.netkeiba.com/race/{race_ref.race_id}/"`.
   - Call `html = session.fetch_with_retry(url)`. If `html is None`: log error, return None.
   - Content validation: if `detect_block_page(html)`: log warning "block/empty page detected for {race_id}", return None.
   - ATOMIC WRITE: `out_dir.mkdir(parents=True, exist_ok=True)`; write to a temp file `out_path.with_suffix(".html.tmp")` with `encoding="utf-8"`; then `os.replace(tmp_path, out_path)` (atomic on the same filesystem). Per Codex Review HIGH/MEDIUM — interruption must never leave a non-empty partial file that future runs treat as valid.
   - Return `out_path` on success.

5. `def make_fetch_html_callable(session: FetcherSession) -> Callable[[str], Optional[str]]`:
   - Returns a closure `lambda url: session.fetch_with_retry(url)` so enumeration (Plan 02) can use the same session without owning the browser.

Imports: `import os`, `import re`, `import time`, `from pathlib import Path`, `from typing import Callable, Optional`, `from loguru import logger`, `from playwright.sync_api import sync_playwright, TimeoutError as PlaywrightTimeout`, `from src.scraper.models import RaceRef`. Do NOT modify `src/scraper/__init__.py`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Denial of Service | Rate-limit abuse of netkeiba | mitigate | Sequential requests with 2s delay on BOTH success and error paths; one browser reused per batch; retry uses exponential backoff. |
| T-04-07 | Tampering | Partial HTML file left by interruption | mitigate | Atomic write (temp + os.replace); zero-byte files trigger re-fetch; block-page detection rejects empty/anti-bot responses. |
| T-04-08 | Elevation of Privilege | Anti-bot detection by netkeiba | mitigate | Playwright renders like a real browser; `domcontentloaded` wait avoids hanging on persistent connections; block-page detection surfaces failures instead of silently saving junk. |
| T-04-09 | Information Disclosure | Raw HTML at rest | accept | Stored locally only; never transmitted externally; spec forbids public sharing. |
</threat_model>
