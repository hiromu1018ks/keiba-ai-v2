2. `class FetcherSession`:
   - A context manager (`__enter__` / `__exit__`) that launches ONE Playwright Chromium browser and ONE BrowserContext for the entire batch. Cleanup MUST be in `__exit__` via try/finally so a crash mid-batch still closes the browser.
   - Constructor params: `headless: bool = True`, `rate_limit_seconds: float = RATE_LIMIT_SECONDS`, `navigation_timeout_ms: int = 30000`, `wait_until: str = "domcontentloaded"` (NOT `"networkidle"` per Cycle-1 MEDIUM — networkidle is unreliable on pages with persistent requests).
   - `__enter__` starts `sync_playwright()`, launches `p.chromium.launch(headless=headless)`, creates `browser.new_context()` and one reusable `page = context.new_page()`. Returns `self`.
   - `__exit__` closes page/context/browser and stops playwright, all in a try/finally.
   - Method `fetch(url: str) -> Optional[str]`: navigates `self.page.goto(url, wait_until=self.wait_until, timeout=self.navigation_timeout_ms)`, returns `self.page.content()`. On `PlaywrightTimeout`/Exception: log warning with attempt counter, return None. Applies `time.sleep(self.rate_limit_seconds)` on BOTH success and error paths (Cycle-1 MEDIUM — server errors must not trigger unthrottled retries).
   - Method `fetch_with_retry(self, url: str, retries: int = MAX_RETRIES) -> Optional[str]`: calls `self.fetch` up to `retries` times with exponential backoff (base `RATE_LIMIT_SECONDS * (attempt + 2)`). Returns the HTML string on success, or None after exhausting retries (per Cycle-1 HIGH — do NOT return a path on failure).
