Per D-02 (BS4+lxml for parsing), D-03 (all fields obtainable), D-09 (no schema gaps):

Create `src/scraper/parser.py` with these functions:

1. `parse_horse_weight(text: str) -> tuple[Optional[int], Optional[int]]`:
   - Handles: "456(+4)" -> (456, 4), "478(-2)" -> (478, -2), "472(0)" -> (472, 0)
   - Handles: "計不", "---", "" -> (None, None)
   - Handles: "456" without parentheses -> (456, None)
   - Uses re.match(r'(\d+)\(([+-]?\d+)\)', text.strip())

2. `parse_sex_age(text: str) -> tuple[Optional[str], Optional[int]]`:
   - Handles: "牡4" -> ("牡", 4), "牝3" -> ("牝", 3), "セ5" -> ("セ", 5)
   - Returns (None, None) for empty/short text

3. `parse_race_flags(race_condition: str) -> dict[str, Optional[bool]]`:
   - Per D-10: derives race_flag_* from condition text using regex/substring matching
   - Parenthetical modifiers: "(ハンデ)" -> race_flag_handicap=True, "(牝)" -> race_flag_mare_only=True, "(馬齢)" -> race_flag_age_restricted=True
   - Class detection: "未勝利"/"新馬" -> race_flag_maiden=True, "オープン" -> race_flag_open=True
   - Grade: re.search(r"(GI|GII|GIII|重賞)" -> race_flag_graded_stakes=True, race_flag_stakes=True
   - Weight type: "(別定)" -> race_flag_special_weight=True, "(定量)" -> race_flag_bonus_weight=True, "(ハンデ)" -> race_flag_handicap=True
   - Other: "(国際)" -> race_flag_graded_stakes=True, "(特指)" -> race_flag_special_weight=True, "(見習騎手)" -> race_flag_apprentice=True
   - Allowance: "(混)", "(市)", "九州産馬" -> race_flag_allowance=True
   - Condition: "(指)", "[指]", "(抽)", "[抽]" -> race_flag_condition_race=True
   - Fields not derivable from text (race_flag_colt_only, race_flag_gelding_only, race_flag_stallion_only, race_flag_amateur, race_flag_female_jockey, race_flag_young_horse, race_flag_listed) -> None
   - All flag keys must match exactly the field names in RaceSchema

4. `parse_race_html(html_path: Path) -> dict`:
   - Reads HTML with encoding="utf-8"
   - Returns dict with keys "race" (dict), "entries" (list[dict]), "results" (list[dict])
   
   Race header extraction:
   - Race date from `<p class="smalltxt">`: regex r'(\d{4})年(\d{2})月(\d{2})日' -> "YYYY-MM-DD"
   - Meeting info: regex r'(\d)回(\w+)(\d)日目' -> meeting_num (int), course_name, meeting_day (int)
   - course_code: map course_name to code using COURSE_CODE_MAP (東京=05, 中山=06, 京都=08, 阪神=09, 福島=02, 新潟=03, 札幌=01, 函館=02, 中京=07, 小倉=10) -- NOTE: verify this matches Kaggle codes
   - Race condition text: same `<p class="smalltxt">` element, after date/meeting info -> race_condition
   - Race flags: call parse_race_flags(race_condition)
   - Course info from `<diary_snap_cut>` span or `<p>`: regex for surface/direction/distance (e.g., "ダ右1200m" -> surface="ダート", direction="右", distance=1200; "芝左1600m" -> surface="芝", direction="左", distance=1600)
   - Weather: regex r'天候\s*:\s*(\S+)' -> weather
   - Track condition: regex r'(芝|ダート)\s*:\s*(\S+)' -> track_condition (NOTE: use second capture group)
   - Start time: regex r'発走\s*:\s*(\d{2}:\d{2})' -> start_time
   - Race name: from `<h1>` tag -> race_name; grade from race_condition or h1 text (G1/G2/G3 pattern)
   - race_id: extracted from html_path stem (filename without .html)
   - head_count: count of rows in result table
   - obstacle: "障害" in race_condition -> "障害" else None
   - race_number: from URL or race_id last 2 digits
   - grade_revision: extract if present (e.g., "第XX回" pattern), else None
   
   Result table extraction (table with class "race_table_01" or "race_table_01 nk_tb_common"):
   - For each data row (skip header tr), extract td columns by index:
     - col 0: 着順 (finish position) -- may be numeric or text like "中"/"取"/"失"/"除"/"再"
     - col 1: 枠番 -> bracket_num
     - col 2: 馬番 -> horse_number
     - col 3: 馬名 -> horse_name
     - col 4: 性齢 -> sex, age via parse_sex_age
     - col 5: 斤量 -> weight_assigned (float)
     - col 6: 騎手 -> jockey
     - col 7: タイム -> finish_time
     - col 8: 着差 -> margin
     - col 9: 通過 (passing positions) -> corner_1 through corner_4 (parse "-(\\d+)-(\\d+)-(\\d+)-(\\d+)" pattern)
     - col 10: 上り -> last_3f (float)
     - col 11: 単勝 -> win_odds (float, post-race per D-03)
     - col 12: 人気 -> popularity (int, post-race per D-03)
     - col 13: 馬体重 -> horse_weight, weight_change via parse_horse_weight
     - col 14: 調教師 -> trainer; extract region from prefix [東]/[西] per D-12
     - col 15: 馬主 -> owner
     - col 16: 賞金 -> prize_money (float) per D-13
   
   Per-row processing:
   - Build horse_race_id = f"{race_id}_{horse_number:02d}"
   - Finish position handling per kaggle_converter.py pattern: null_notes = {"中", "取", "失", "除", "再"}
     - If 着順 is numeric: finish_position = int, finish_note = None
     - If 着順 in null_notes: finish_position = None, finish_note = 着順 text
     - If 着順 has 降 note: finish_position preserved, finish_note = "降"
   - Split each row into entry dict (pre-race fields) and result dict (post-race fields) per schema separation
   
   Obstacle race detection:
   - If "障害" in race_condition: set obstacle = "障害" in race dict

Imports: from pathlib import Path, import re, from typing import Optional, from bs4 import BeautifulSoup, from loguru import logger

Define COURSE_CODE_MAP as module-level dict mapping Japanese course names to 2-digit string codes.
