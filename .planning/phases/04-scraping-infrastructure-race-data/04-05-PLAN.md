3. `def validate_integrity(race_df, entry_df, result_df) -> list[str]`:
   - Returns a list of human-readable violation strings (empty list = clean). Codex Review MEDIUM.
   - Checks:
     a. `race_df["race_id"].is_unique` (after dropping NaN); else "duplicate race_id: {list}".
     b. `entry_df["horse_race_id"].is_unique`; else "duplicate horse_race_id".
     c. `result_df["horse_race_id"].is_unique`; else "duplicate horse_race_id in result".
     d. `set(entry_df["horse_race_id"]) == set(result_df["horse_race_id"])` (1-to-1); else "entry/result horse_race_id mismatch".
     e. `set(entry_df["race_id"]).issubset(set(race_df["race_id"]))` (FK); else "orphan entry race_id".
     f. `set(result_df["race_id"]).issubset(set(race_df["race_id"]))`; else "orphan result race_id".
   - Log each violation at WARNING level. Do NOT raise (return list, caller decides).
