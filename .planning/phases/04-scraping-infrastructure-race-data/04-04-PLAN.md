Create `src/scraper/normalizer.py` with:

1. `normalize_to_parquet(parsed_races: list[dict], standard_dir: Path = Path("data/standard")) -> dict[str, Path]`:
   Following kaggle_converter.py convert() pattern (build DataFrames -> validate -> write -> audit):

   a. Accumulate rows from parsed_races list:
      - race_rows: parsed["race"] for each parsed
      - entry_rows: extend with parsed["entries"] for each parsed
      - result_rows: extend with parsed["results"] for each parsed

   b. Build DataFrames:
      - race_df = pd.DataFrame(race_rows)
      - entry_df = pd.DataFrame(entry_rows)
      - result_df = pd.DataFrame(result_rows)

   c. Filter obstacle races:
      - If obstacle column exists in race_df: filter out rows where obstacle == "障害"
      - Track filtered race_ids and remove corresponding entries/results
      - Log count of obstacle races dropped

   d. Ensure string dtypes (same pattern as kaggle_converter.py lines 255-257, 263-265):
      - Race table: cast race_id, course_code, race_date to str
      - Entry table: cast horse_race_id, race_id to str
      - Result table: cast horse_race_id, race_id to str

   e. Run audit_leakage (same pattern as kaggle_converter.py lines 123-129):
      - audit_leakage([RaceSchema], race_df, "scraped race table generation")
      - audit_leakage([EntrySchema], entry_df, "scraped entry table generation")
      - Log warnings if leaked columns found (do NOT raise per D-12)

   f. Write Parquet files:
      - standard_dir.mkdir(parents=True, exist_ok=True)
      - Write race_scraped.parquet, entry_scraped.parquet, result_scraped.parquet (separate from Kaggle files per RESEARCH.md Open Question 1)
      - Use engine="pyarrow", compression="snappy", index=False (same as kaggle_converter.py line 117)
      - Log row counts per table

   g. Return dict mapping table names to output paths

Imports: from pathlib import Path, import pandas as pd, from loguru import logger, from src.schemas.audit import audit_leakage, from src.schemas.race import RaceSchema, from src.schemas.entry import EntrySchema
